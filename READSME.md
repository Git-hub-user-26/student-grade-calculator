# Student Grade Calculator

A console-based Java application that calculates student grades based on subject marks.

## Features
- Input multiple students and subjects
- Calculates average marks automatically
- Assigns grades based on standard grading scale (O, A+, A, B+, B, F)
- Displays a formatted result table

## How to Run
```bash
javac GradeCalculator.java
java GradeCalculator
```

## Grading Scale
| Grade | Marks Range |
|-------|------------|
| O     | 90 - 100   |
| A+    | 80 - 89    |
| A     | 70 - 79    |
| B+    | 60 - 69    |
| B     | 50 - 59    |
| F     | Below 50   |

## Usage
Run the program, enter number of students, their names, number of subjects, and marks when prompted.
