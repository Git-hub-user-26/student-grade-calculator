Title: Student Grade Calculator

1. Problem
Manual grade calculation in classrooms is error-prone and time-consuming.
This tool automates the process for any number of students and subjects.

2. Approach
Built using core Java concepts: loops, arrays, ArrayLists, Scanner input,
string formatting, and conditional logic — all covered in this course.

3. Key Decisions
- Used ArrayList for dynamic student count instead of fixed arrays
- Kept it single-file for simplicity and portability

4. Challenges
- Handling varied subject counts per student
- Formatting console output into a clean readable table

5. What I Learned
Applying OOP-adjacent thinking in a procedural Java structure, and the
importance of clean output formatting for usability.
